Digonto Vector 1.1
==================
Draw logos, shapes and illustrations. The layout is like CorelDRAW, but easy.

Tools (left): Select (V), Node edit (A), Pen (P), Rectangle (R), Ellipse (E), Polygon (G), Star (S), Line (L),
Freehand (B), Text (T), Eyedropper (I), Zoom (Z), Pan (H or hold Space).

Colours: click a colour at the bottom for the fill, right-click for the outline. The Fill panel has gradients,
outline width, dashes, corners and opacity.

Shaping: Weld, Trim, Intersect, Front minus back, Back minus front. Also Combine / Break apart, Group / Ungroup,
Outline to object, Contour (offset copies), Text to curves, Mirror, Rotate, Align and Distribute, Step and repeat.

Precision: rulers in mm, guides (drag from a ruler), grid, snapping to objects / guides / page,
type exact X, Y, W, H in the bar on top. Page size is set in File > Page size.

Files: .dvec (own format, keeps everything editable). Open and import SVG, AI, EPS and PDF. Export SVG, EPS and AI,
PDF (vector, exact page size) and PNG (any dpi, transparent background).
Working with Inkscape and Illustrator: use SVG. Layers (names, hidden, locked) stay layers, text stays editable text
(font, size, bold, italic, colour), groups and object names are kept - in both directions.
Import limits: pictures inside AI/EPS/PDF files are skipped, PDF text becomes outlines, only page 1 of a PDF is read.
EPS gradients and shapes are exported as real paths, so they stay editable in Illustrator and Inkscape.

Layers (right column, like Photoshop): Navigator, Properties, Colour, History, Layers, Align, Shaping, Effects.
Layers can be shown, hidden, locked, renamed and re-ordered; the History list lets you jump back to any step.

More: Image trace (logo/scan to vector, black-and-white or colour), Clip to shape, Blend, Round corners, Skew,
Wireframe view (View menu).

Not in this version: AI/EPS files, embedded photos, clipping masks, blends. Text is outlined by "Text to curves"
before sending a file to someone who does not have your font.
Only PySide6-Essentials is installed, locked with SHA-256 hashes.
